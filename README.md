# 🚀 BizPilot AI – AI Business Copilot for SMEs

> Transforming Small Businesses with Intelligent Automation

BizPilot AI is an AI-powered Business Copilot designed to help Small and Medium Enterprises (SMEs) streamline operations, automate repetitive tasks, and make data-driven decisions through intelligent business insights.

Built as part of the **TakeOver'26 AI Hackathon**, the platform combines business management with Generative AI to simplify inventory management, quotation generation, analytics, and decision-making—all within a modern, intuitive dashboard.

---

## 🌟 Problem Statement

Many Small and Medium Enterprises still rely on manual processes, spreadsheets, and disconnected tools to manage their daily operations. This leads to inefficient workflows, inventory issues, delayed decision-making, and increased operational costs.

BizPilot AI addresses these challenges by providing an AI-powered business assistant that centralizes business operations, automates routine tasks, and delivers intelligent recommendations using Generative AI.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/BizPilot-AI.git
```

Navigate into the project

```bash
cd BizPilot-AI
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
